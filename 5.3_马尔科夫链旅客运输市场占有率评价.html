PART 02 · 原理说明

原理说明
马尔科夫分析法

PRINCIPLE
核心定义 — 状态转移概率 · 转移矩阵 · 稳态分布
5.3.2 · 核心定义

一步状态转移概率 · k步状态转移概率 · 概率约束

1一步状态转移概率

在 $t$ 时刻系统 $X_t$ 从状态 $i$ 转移到下一时刻状态 $j$ 的条件概率：

符号：$P(X_{t+1}=j \mid X_t=i)$，简写 $P_{ij}$ 表达式：$P_{ij} = P(X_{t+1}=j \mid X_t=i)$
2k步状态转移概率

在 $t$ 时刻从状态 $i$ 转移到 $t{+}k$ 时刻状态 $j$ 的条件概率（经过 $k$ 个单位时间）：

$P(X_{t+k}=j \mid X_t=i)$，简写 $P_{ij}^{(k)}$

表达式：$P_{ij}^{(k)} = P(X_{t+k}=j \mid X_t=i)$

3概率约束条件
所有状态转移概率非负：$0 \leq P_{ij} \leq 1$，$0 \leq P_{ij}^{(k)} \leq 1$ 转移矩阵每行概率之和为 1：$\sum_{j} P_{ij} = 1$，$\sum_{j} P_{ij}^{(k)} = 1$
5.3.2 · 关键概念 1–2

k步转移矩阵与正规概率矩阵

n个状态 → n×n 矩阵，行和为 1

1k步转移矩阵 $P^{(k)}$

系统含 $n$ 个状态时，由所有 $k$ 步转移概率 $P_{ij}^{(k)}$ 构成的 $n \times n$ 矩阵，记为 $P^{(k)}$；下图为本案例的 $4 \times 4$ 一步转移矩阵 $P$：

$P$ = $P_{AA}$ $P_{AB}$ $P_{AC}$ $P_{AD}$
$P_{BA}$ $P_{BB}$ $P_{BC}$ $P_{BD}$
$P_{CA}$ $P_{CB}$ $P_{CC}$ $P_{CD}$
$P_{DA}$ $P_{DB}$ $P_{DC}$ $P_{DD}$

特殊形式：一步转移矩阵（$k=1$），简记为 $P$

2正规概率矩阵
$\exists\, m > 0$，使 $P_{ij}^{(m)} > 0$ 对所有 $i,j$ 成立

存在正整数 $m$，使得矩阵 $P^{(m)}$ 中所有元素均大于 0。

意义：保证马尔科夫链长期演化后收敛到唯一的稳态分布——这是后续求解平衡向量 $S^{*}$ 的前提。

逻辑链条
转移矩阵 P→ 正规概率矩阵→ 长期演化收敛
确保收敛到唯一稳态分布 —— 这也是后续求解平衡向量 $S^{*}$ 的前提
5.3.2 · 关键概念 3–4

状态概率向量与平衡向量

从"状态概率向量"递推到"稳态分布"

3状态概率向量

记 $S_i(t) = P(X_t = i)$ 为系统在 $t$ 时刻处于状态 $i$ 的概率，则 $t$ 时刻的状态概率向量为：

$S(t) = [S_1(t),\, S_2(t),\, \dots,\, S_n(t)]$

初始状态向量：$t=0$ 时的状态概率向量，记为 $S(0) = [S_1(0),\, S_2(0),\, \dots,\, S_n(0)]$。本案例 $n=4$，四种运输方式的市场占有率向量即 $S(t) = [S_A(t),\, S_B(t),\, S_C(t),\, S_D(t)]$。

递推关系（核心公式）：由马尔科夫链性质及全概率公式推导，$t$ 时刻向量与 $t{-}1$ 时刻向量满足：

$S(t) = S(t-1) \cdot P$
4平衡向量

定义：存在非零行向量 $S$，满足 $S \cdot P = S$（即向量与转移矩阵相乘后保持不变）。

$S \cdot P = S$

固有概率向量：若平衡向量满足归一化条件 $\sum_{i=1}^{n} S_i = 1$，则称 $S$ 为固有概率向量，即系统的稳态分布 $S^{*}$，对应长期稳定后的市场占有率。

极限收敛（推广）：$S(t) = S(0) \cdot P^{t}$，当 $t \to \infty$ 时 $S(t) \to S^{*}$，且与初始状态 $S(0)$ 无关。

演化路径
$S(0)$→ $S(1)=S(0)P$→ $\cdots$→ $S(k)=S(0)P^{k}$→ $k\to\infty$→ $S^{*}$ —— 稳态分布 $S^{*}$ 满足 $S^{*}P=S^{*}$，即前文的平衡向量（固有概率向量）
5.3.2 · 求解方法

稳态分布 $S^{*}$ 的求解方法

平衡方程 $S P = S$ + 归一化条件 → 唯一稳态分布

推导把 $S P = S$ 展开成线性方程组

设 $S = (S_1, S_2, \dots, S_n)$，由平衡方程 $S P = S$ 移项得 $S(P - I) = 0$，即 $(P^{\mathrm{T}} - I)S^{\mathrm{T}} = 0$；按分量写出：

$\sum_{i=1}^{n} S_i P_{ij} = S_j \quad (j = 1, 2, \dots, n)$

为何必须补归一化条件：由于 $P$ 的每一行元素之和为 1，矩阵 $P^{\mathrm{T}} - I$ 的秩只有 $n-1$，$n$ 个平衡方程中仅有 $n-1$ 个独立，单独求解只能得到一条解直线；再联立 $\sum_{i=1}^{n} S_i = 1$，解才唯一。

步骤四步求解流程
1

写出平衡方程

按 $\sum_{i} S_i P_{ij} = S_j$ 展开，共 $n$ 个方程。

2

替换冗余方程

舍去其中任一冗余方程，用 $\sum_{i} S_i = 1$ 补位，凑成 $n$ 元方程组。

3

解线性方程组

手算消元，或用矩阵求逆（R 中 solve()）直接求解。

4

回代验证

检验 $S^{*}P = S^{*}$ 且 $\sum_{i} S_i^{*} = 1$。

二状态算例
$P = \begin{bmatrix} 0.8 & 0.2 \\ 0.3 & 0.7 \end{bmatrix}$ → 由 $S_1 = 0.8S_1 + 0.3S_2$ 得 $0.2S_1 = 0.3S_2$ + $S_1 + S_2 = 1$ → $S^{*} = (0.6,\ 0.4)$

5.3.2 · 预测公式

马尔科夫预测分析 — 逐期递推

推导 1设上期占有率向量
$S(0) = (S_A(0),\, S_B(0),\, S_C(0),\, S_D(0))$

则本期旅客运输市场的占有率向量为：

$S(1) = S(0) \cdot P$
$= (S_A(1),\, S_B(1),\, S_C(1),\, S_D(1))$
推导 2展开的分量公式
$S_A(1) = S_A(0){\cdot}P_{AA} + S_B(0){\cdot}P_{BA} + S_C(0){\cdot}P_{CA} + S_D(0){\cdot}P_{DA}$
$S_B(1) = S_A(0){\cdot}P_{AB} + S_B(0){\cdot}P_{BB} + S_C(0){\cdot}P_{CB} + S_D(0){\cdot}P_{DB}$
$S_C(1) = S_A(0){\cdot}P_{AC} + S_B(0){\cdot}P_{BC} + S_C(0){\cdot}P_{CC} + S_D(0){\cdot}P_{DC}$
$S_D(1) = S_A(0){\cdot}P_{AD} + S_B(0){\cdot}P_{BD} + S_C(0){\cdot}P_{CD} + S_D(0){\cdot}P_{DD}$
推导 3逐期递推 → 长期预测

下一期的预测结果（用 $S(1)$ 代入同理展开）：$S(2) = S(1) \cdot P = S(0) \cdot P^{2}$

$$S(k+1) = S(0) \cdot P^{(k+1)}$$

可以得到经过若干时间间隔后系统所处状态的概率 —— 这是整个预测的核心公式。

5.3.3 · 稳态分布

求解稳态分布 $S^{*}$ — 长期市场格局

联立 $S P = S$ 与 $\sum_i S_i = 1$，解出唯一稳态分布

STEP 6建立稳态方程组

把一步转移矩阵 $P$ 代入 $\sum_i S_i P_{ij} = S_j$，移项后得：

(1) $-0.231S_A + 0.029S_B + 0.005S_C + 0.088S_D = 0$
(2) $\phantom{-}0.115S_A - 0.129S_B + 0.024S_C + 0.059S_D = 0$
(3) $\phantom{-}0.077S_A + 0.079S_B - 0.036S_C + 0.118S_D = 0$
(4)（归一化）$S_A + S_B + S_C + S_D = 1$

四个平衡方程中只有 3 个相互独立（第 4 个冗余），故保留 (1)~(3) 并用归一化条件替入，从而得到唯一解。

稳态分布取决于转移矩阵 $P$，与初始状态 $S(0)$ 无关，是市场演化的长期终态。

注：若改用未舍入的精确转移概率，解得 $S^{*}=(0.056,\,0.201,\,0.700,\,0.043)$，结论一致。

# 求解稳态分布：S·P = S 且 sum(S) = 1（P 同上一页，便于单独运行）
P <- matrix(c(0.769,0.115,0.077,0.039, 0.029,0.871,0.079,0.021,
              0.005,0.024,0.964,0.007, 0.088,0.059,0.118,0.735),
            nrow = 4, byrow = TRUE)
s_steady <- function(P) {
  n <- nrow(P)
  A <- t(P) - diag(n)     # (P^T - I) S = 0
  A[n, ] <- 1              # 末行换成归一化条件
  b <- c(rep(0, n - 1), 1)
  solve(A, b)
}
s_star <- s_steady(P)
round(s_star, 3)            # 0.057 0.200 0.700 0.043
round(s_star %*% P, 3)      # 回代验证：S*·P = S*

稳态分布 = 长期（$k\to\infty$）收敛后的状态分布，由 $S^{*}P = S^{*}$ 与 $\sum_{i} S_i^{*} = 1$ 联立解出，也即前文所称的平衡向量（固有概率向量）。

ANALYSIS对比分析

由表5-3-2可将四种运输方式的市场占有率作稳态分布与初始状态的对比，可以看出航空、铁路、水路三种运输方式相较于初始状态都有所提升，分别提升了3.4%、8.1%、1.8%，而公路下降了13.3%，说明旅客的出行方式选择正慢慢趋向于多元化。

旅客在选择出行方式时，会考虑多种因素，包括价格、速度、舒适度、安全性等，这些因素都会影响运输企业的竞争力和客户满意度。

因此，各运输企业要在旅客运输市场中取得应有的市场占有率、决策出更好的营销策略，就必须了解旅客的出行选择行为模式；必须依靠高速度、高技术、高质量的服务去参与竞争，着眼于为旅客提供更适宜的服务，力求更大限度地满足旅客需求。

5.3.4 · 结语

总结

本研究以某省旅客运输市场为对象，通过马尔科夫分析法，系统完成了从数据调研到市场预测的全流程探索。我们先基于2009-2010年旅客流动数据，计算出保持概率与转向概率，构建起一步转移矩阵；再以2010年末市场占有率为初始状态向量 $S(0)$，成功预测出2011-2012年短期市场格局，并由稳态方程组解出稳态分布 $S^{*}$下各运输方式的占有率。

结果清晰显示，随着时间推移，旅客出行方式正从以公路为主导，逐步向航空、铁路、水路多元化方向发展——航空、铁路、水路占有率分别提升3.4%、8.1%、1.8%，公路则下降13.3%。这一变化既反映了旅客对出行体验（速度、舒适度等）需求的升级，也为运输市场的发展指明了方向。
